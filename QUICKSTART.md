# Быстрый старт

## 1. Установите зависимости
```bash
npm install
```

## 2. Настройте .env файл
Откройте `.env` и замените:
- `PLATEGA_MERCHANT_ID` - ваш merchant ID из Platega
- `PLATEGA_SECRET` - ваш secret key из Platega
- `WEBHOOK_URL` - ваш домен (например: https://bot.example.com)

## 3. Запустите бота
```bash
npm start
```

Или для разработки с автоперезагрузкой:
```bash
npm run dev
```

## 4. Проверьте работу
- Откройте бота в Telegram
- Нажмите /start
- Проверьте меню
